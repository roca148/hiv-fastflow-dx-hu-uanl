# VIH Lab · Protocolo académico interactivo

Abre `index.html` en un navegador. Es un HTML autónomo, sin dependencias ni conexión necesaria para sus actividades. Los enlaces a las fuentes sí requieren internet.

Incluye panel de progreso, ruta diagnóstica, ventanas por ensayo, gráfica de carga viral, calculadoras de descenso logarítmico y fold change, resistencia y tropismo, caso clínico original de cuatro decisiones y autoevaluación con explicaciones. Permite exportar un resumen e imprimir.

Base conceptual: García F et al. Enferm Infecc Microbiol Clin. 2011;29(4):297–307. DOI: https://doi.org/10.1016/j.eimc.2010.12.006. Se distingue explícitamente el algoritmo histórico del artículo de la ruta CDC y las referencias NIH consultadas el 16/10/2026. La bibliografía completa está dentro del HTML.

Uso formativo para estudiantes de medicina, adultos y adolescentes. Caso y series totalmente simulados. No es un protocolo institucional validado ni un sistema de diagnóstico o prescripción. Aplicar normas locales en la práctica clínica.

El progreso se almacena solo en el navegador si localStorage está disponible; no se recaban datos personales ni se envían a servidores.

Verificación: navegación, rutas diagnósticas, gráficas, cálculos y validación numérica, caso completo, cuestionario incompleto/completo, persistencia, reinicio, descarga y ocho vistas a 390 px; sin errores JavaScript en Chrome.
